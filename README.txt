HNCPL Attendance Mini App - first frontend prototype

Upload these 3 files to an HTTPS static host:
index.html
style.css
app.js

This is only the UI/demo. It does NOT connect to hncpl_attendance.db.
Never upload hncpl_attendance.db, .env, or BOT_TOKEN to GitHub.
